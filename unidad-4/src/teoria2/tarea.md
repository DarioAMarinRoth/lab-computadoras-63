# Tarea

Crear una clase que se llame `Materia`.

## Atributos:

- String: nombre
- int: nota

## Métodos:

### Constructores:

- Constructor que solicite 'nombre'.
- Constructor que solicite 'nombre' y 'nota'.

### Otros métodos:

- `void`: `mostrarInformación()` -> muestre el nombre y la nota.
- `boolean`: `estaAprobada()` -> Devolver `true` si la nota es >= 7.
- getter de nombre
- getter de nota
- setter de nota: tiene que validar que la nota este entre 1 y 10.
